### `02` FLAGSHIP RESEARCH SPECIFICATION

#### AERES 2.0 // Architectural Engineering Reasoning Engine `Concept / Research`
*Cross-discipline knowledge graph and blast-radius analysis for built-environment records.*

In architectural engineering, building information is fragmented across CAD/PDF drawings, BIM models, specifications, and building codes. When an element changes—such as relocating a structural column—downstream clashes across other disciplines are traced manually. AERES explores automated change-impact analysis by converting heterogeneous records into an auditable knowledge graph evaluated by deterministic geometric and rule solvers.

<p align="center">
  <img src="./assets/aeres-illustration.svg" alt="AERES Research Concept: Cross-Discipline Change Impact Analysis" width="100%">
</p>

* **Core Focus**: Cross-document entity resolution, blast-radius dependency traversal, and automated discrepancy checks.
* **Proposed Architecture**: FastAPI · Neo4j Property Graph · PostgreSQL Spatial · PyTorch · OpenCV · Three.js
* *Status Note*: Concept and research specification stage. Capabilities represent proposed architectural designs, not operational software.
